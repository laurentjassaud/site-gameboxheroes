Particularités des boîtes

Mode assisté

Toutes les boîtes auront la possibilité de jouer dans un mode assisté qui vérifiera la légalité des actions. Les règles seront implémentées en incluant les Questions & Answers du forum BoardGameGeek. Bien sûr, un mode libre permettra aux joueurs de jouer sans assistance.

Parties optimisées en « face à face »

Amélioration de l’expérience de jeu par double aveugle, partie chronométrée type blitz et ajout de toutes les variantes, notamment celles créées par les fans.

Jeu solo

Pour les jeux solos, l’interface de la boîte active rigoureusement tout le système du moteur solo. Différents niveaux de contrôle permettent soit de tirer soi-même les dés sur les différents flowcharts, soit de laisser l’interface résoudre les réponses du moteur de jeu pour ne se consacrer qu’à la stratégie.

Pour les jeux prévus à deux joueurs, un travail sur une IA symbolique est en cours : il permettra d’avoir un adversaire compétent sur tous les jeux.
